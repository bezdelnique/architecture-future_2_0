Мое понимание стека для работы с данными

| Слой                                         | Технология      | Роль                                                |
|----------------------------------------------|-----------------| --------------------------------------------------- |
| Хранилище                                    | MinIO           | хранит parquet/metadata файлы                       |
| Управление данными + метаданными хранилища   | Iceberg         | делает lakehouse-таблицы                            |
| Каталог, версионирование                     | Nessie          | каталог Iceberg + branches/tags                     |
| Семантических слой                           | Dremio          | SQL, virtual datasets, acceleration, semantic layer |
| Управление метаданными (Metadata governance) | DataHub         | lineage, ownership, glossary, discoverability       |
| BI / dashboards                              | Apache Superset | отчеты, графики, self-service                       |

DataHub позволяет работать с данными в разрезе бизнес-домена. Dremio - создание семантического слой, т.е. некая нормализация, общие правила того как мы смотрим на данные на самом низком уровне. Что такое покупка, продажа, клиент и т.д. 


## Ключевые бизнес-сценарии
- Быстрая подготовка отчётности
- Независимое развитие финтех- и ИИ-направлений
- Масштабирование для новых бизнесов


## Границы бизнес-доменов
- Головной офис;
- Клиники;
- Компания, предоставляющая ИИ-сервисы для работы с медицинскими данными;
- Компания, оказывающая финтех-услуги и обладающая банковской лицензией.
